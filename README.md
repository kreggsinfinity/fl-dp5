# 🎯 Interactive English Quiz Challenge (Repository 5 / Variety 5)

Automated video generator for **10-Second English Challenges & Fill-in-the-Blank Quizzes** in 9:16 vertical reels.

## 🌟 Key Features
- **Gamified Format**: Dynamic Question display -> 5-second countdown timer bar -> Animated answer reveal -> Grammar breakdown.
- **High Comment Rate**: Naturally prompts viewers to comment their scores ("I got it right!", "Explain why B!"), driving Facebook algorithmic reach.
- **Clear Explanations**: Concise rules explaining why the correct choice works.
- **Multi-Level Content**: CEFR A2 through C1 grammar and vocabulary puzzles.

## 🚀 How to Run
```bash
# 1. Generate quiz reel
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/interactive_quiz_reel.mp4 output/run_XXXX/metadata.json
```

## 📱 Recommended Facebook Page Target
- **Page Concept**: *Daily English Quiz Challenge / Test Your English*
- **Target Audience**: Active learners who love testing their knowledge and competing with friends in comments.
